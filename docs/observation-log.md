# Two-week observation log

Observation starts only after the measured 5×2 benchmark is accepted and its
routing recommendation is applied. Keep one row per production task; do not
record prompts, credentials, or raw transcript content here.

| Date | Task/source | Run directory | Role/model/effort | Retries | First/final checks | Human corrections | Rate-limit event | Billing evidence checked | Destructive or recursion event | Success | Notes |
|---|---|---|---|---:|---|---:|---|---|---|---|---|

## Exit criteria

- At least fourteen calendar days and the five representative task types are
  covered.
- Accidental API billing, data loss/change mixing, and unbounded recursion or
  retry loops remain at zero.
- Any major incident disables automatic activation immediately and records the
  rollback time, backup used, and recovery verification.
